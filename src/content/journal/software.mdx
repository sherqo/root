I love software because it's **leverage**. It's the closest thing to telling a computer to do exactly what you imagine and having it happen. Learning it properly changes how you think. It makes you more structured and more curious about how things work underneath.

I care about the last pixel: UX that feels exceptional and software that sucks less than it has to.
Some things I've built:

- [**Yaleeq**](https://www.yaleeq.net) - internship platform for students, by students. More on the [Yaleeq page](/journal/yaleeq).
- [**Diran**](https://github.com/sherqo/diran) - a Notion-style block editor, built solo. Every block is a database row. Building it taught me a lot about databases. Not currently deployed, but the code's open source.
- [**Raft**](https://github.com/sherqo/raft) - worked through the paper and a reference implementation to understand distributed consensus.
- [**Packet Pulse Protocol**](https://github.com/sherqo/packet-pulse-protocol) - a lightweight UDP protocol for IoT sensor telemetry: batching, sequence tracking, loss-tolerant delivery. This was my first real spark into computer networks.
- [**Distributed LLM Serving System**](https://github.com/sherqo/llm-cluster-orchestrator) - a distributed system in Go and Python that handles 1000+ concurrent LLM inference requests. Custom load balancer, agent-based auto-scaling across multiple machines, gRPC-based fault detection, zero request loss on node failure.
- [**lifeops**](https://github.com/sherqo/lifeops) - a TUI app in Go for managing notes, journaling, todos, habits, and a calendar. Built for myself.
- [**Jigsaw Puzzle Solver**](https://jigsaw.sherqo.me/) - a [university project](https://github.com/sherqo/jigsaw-puzzle-solver) that solves jigsaw puzzles from scrambled pieces.
- [**dotfiles**](https://github.com/sherqo/dot-files) - arch btw ;)
